# 1. Introdução à Linguagem Go

Go (ou Golang) é uma linguagem de programação criada pelo Google em 2009.

Ela foi desenvolvida para ser:
- Simples
- Rápida
- Concorrente
- Compilada

## Principais Características

| Característica | Descrição |
|---|---|
| Compilada | Código convertido para binário |
| Concorrência | Suporte nativo com goroutines |
| Simples | Sintaxe limpa |
| Performance | Próxima de C/C++ |

## Instalação

Acesse o site oficial:

https://go.dev

## Verificando Instalação

```bash
go version
```

Resultado esperado:

```bash
go version go1.24 windows/amd64
```

!!! note "Dica"
    Utilize VSCode com a extensão oficial Go.
