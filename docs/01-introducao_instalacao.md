# 1. Introdução à Linguagem Go

Go (também conhecida como Golang) é uma linguagem de programação de código aberto criada pelo Google e lançada oficialmente em 2009.

Ela foi desenvolvida por Robert Griesemer, Rob Pike e Ken Thompson com o objetivo de criar uma linguagem moderna que combinasse simplicidade, alto desempenho e facilidade para desenvolvimento de sistemas escaláveis.

Atualmente, Go é amplamente utilizada no desenvolvimento de:

- APIs REST
- Microsserviços
- Aplicações Web
- Ferramentas de linha de comando (CLI)
- Sistemas distribuídos
- Computação em nuvem (Cloud Computing)
- DevOps e Infraestrutura

## Por que utilizar Go?

A linguagem Go foi criada para resolver problemas encontrados em linguagens tradicionais, oferecendo:

- Código simples e fácil de manter
- Compilação extremamente rápida
- Excelente desempenho em execução
- Gerenciamento automático de memória (Garbage Collector)
- Concorrência nativa através de Goroutines
- Forte suporte para aplicações em nuvem

## Principais Características

| Característica | Descrição |
|---|---|
| Compilada | Código convertido diretamente para binário |
| Concorrência | Suporte nativo através de goroutines |
| Simples | Sintaxe limpa e fácil de aprender |
| Performance | Desempenho próximo ao de C/C++ |
| Multiplataforma | Funciona em Windows, Linux e macOS |
| Open Source | Projeto mantido pela comunidade e pelo Google |

## Instalação

Acesse o site oficial da linguagem:

[:contentReference[oaicite:5]{index=5}](https://go.dev)

Baixe a versão compatível com o seu sistema operacional e siga o assistente de instalação.

## Verificando a Instalação

Após a instalação, abra o terminal e execute:

```bash
go version
```

Resultado esperado:

```bash
go version go1.24 windows/amd64
```

Se uma versão semelhante for exibida, significa que o Go foi instalado corretamente.

!!! note "Dica"
    Recomenda-se utilizar o Visual Studio Code com a extensão oficial Go para obter recursos como autocompletar, depuração e formatação automática de código.
